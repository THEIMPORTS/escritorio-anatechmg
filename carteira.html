Monitorar meu ASIC

O navegador não fala direto com o equipamento (cgminer usa TCP 4028 e o Bitaxe usa HTTP local). Duas formas reais:

1. cgminer — ative a API no minerador com --api-listen e consulte a porta 4028: {"command":"summary"} devolve hashrate, aceitos e rejeitados.
2. Bitaxe / AxeOS — o próprio aparelho serve a interface em http://IP-do-bitaxe e a API em /api/system/info (hashrate, temperatura, shares).
Realidade da mineração: CPU e GPU comuns não dão lucro — a dificuldade da rede tornou isso inviável. Lucro em BTC hoje só com ASIC eficiente e energia barata. Este painel existe para você medir a verdade, não para vender ilusão.
